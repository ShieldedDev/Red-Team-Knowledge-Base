# Introduction to Red Teaming 

### What is Red Teaming?

A red team is a group of hackers with varying backgrounds that test the organisation's infrastructures.

### Attacks performed by Red Teamers:

### 1. Cyber (Digital Attacks: Web, Network & Other Cloud Technologies).
### 2. Social Attacks (Social Engineering, exploiting peoples behaviour).
### 3. Physical Attacks (Physical man-poer, lock picking, etc)

It is similar to pentesting but is more specific and targeted.

Attacks are similar to attack techniques employed by threat actors (APT Advanced Persistent Threat Groups):

1. Red Team Emulation - Copy attack techniques of Threat actors
2. Red Team Simulation - Mimics behaviour of Threat actors.
