# DC01 - Domain Controller Setup

> This guide walks through the deployment of the **Domain Controller (DC01)** for the **evil.corp** Active Directory Red Team Lab. The server acts as the central authentication, DNS, and directory service for the entire lab environment.

---

# Overview

| Property | Value |
|----------|-------|
| Hostname | DC1 |
| Domain | evil.corp |
| NetBIOS Name | E-CORP |
| Operating System | Windows Server 2022 Standard |
| IP Address | 192.168.56.10 |
| Roles | Active Directory Domain Services, DNS |
| Forest Functional Level | Windows Server 2022 |
| Domain Functional Level | Windows Server 2022 |
